# Подключение магазинов: контракт адаптера

Для всех адресов в России обязательные каналы: **Магнит, Пятёрочка, Перекрёсток, ВкусВилл, Купер, Яндекс Еда**. Их карточки отображаются всегда, независимо от результатов OpenStreetMap. Дополнительные сети появляются по данным карты, но **местоположение торговой точки не доказывает возможность доставки**.

## Реально подключено в базовой сборке

- ВкусВилл: официальный публичный MCP-каталог с текущими общекаталожными ценами, но **без проверки адресной корзины**. Для персональных остатков и цен нужен OAuth ВкусВилла.
- Магнит, Пятёрочка, Перекрёсток, Купер, Яндекс Еда: присутствуют как обязательные источники, но **точные цены/наличие/доставка не получаются автоматически**, пока не настроен конкретный адаптер.
- Дополнительные сети: по геопоиску OpenStreetMap; источники цен требуют адаптера.

## Как подключить реальный источник цен

Отдельное backend-приложение-адаптер должно иметь разрешённый доступ к выбранной сети (официальный партнёрский API, MCP, либо авторизованная сессия пользователя в его браузере). Можно развернуть его отдельно. Не пересылайте Cookie, пароли, SMS-коды и платёжные реквизиты нашему приложению; если используется браузер, держите авторизацию внутри защищённого соединения и не выставляйте Chrome DevTools в интернет.

`GROCERYBOT_ADAPTERS_JSON` — JSON-объект с точками входа:

```json
{
  "magnit": {"url": "https://your-magnit-adapter.example/quote", "tokenEnv": "MAGNIT_ADAPTER_TOKEN"},
  "pyaterochka": {"url": "https://your-5ka-adapter.example/quote", "tokenEnv": "PYATEROCHKA_ADAPTER_TOKEN"},
  "perekrestok": {"url": "https://your-perekrestok-adapter.example/quote", "tokenEnv": "PEREKRESTOK_ADAPTER_TOKEN"},
  "kuper": {"url": "https://your-kuper-adapter.example/quote", "tokenEnv": "KUPER_ADAPTER_TOKEN"},
  "yandex_eda": {"url": "https://your-eda-adapter.example/quote", "tokenEnv": "YANDEX_EDA_ADAPTER_TOKEN"}
}
```

`tokenEnv` указывает ИМЯ другой переменной окружения, содержащей токен. Значения токенов не должны попадать в GitHub. В production разрешены только HTTPS endpoints; для локальной разработки допустим `http://localhost`.

### Запрос адаптеру

```http
POST /quote
Content-Type: application/json
Authorization: Bearer <SECRET>
```

```json
{
  "providerId": "magnit",
  "address": "Россия, Сочи, ул. Навагинская, 9",
  "point": {"lat": 43.58, "lon": 39.72, "countryCode": "ru"},
  "allowSubstitutions": true,
  "items": [
    {"id": "i0", "raw": "молоко 2 л", "query": "молоко", "needed": {"quantity": 2000, "unit": "мл"}}
  ]
}
```

### Ответ с подтверждёнными предложениями по адресу

```json
{
  "checkedAt": "2026-11-07T07:00:00Z",
  "addressChecked": true,
  "available": true,
  "stores": [
    {
      "storeId": "magnit",
      "name": "Магнит Экспресс",
      "addressAvailable": true,
      "verifiedDelivery": true,
      "deliveryKopecks": 14900,
      "feesKopecks": 0,
      "minOrderKopecks": 50000,
      "freeDeliveryFromKopecks": 200000
    }
  ],
  "offers": [
    {
      "requestedId": "i0",
      "storeId": "magnit",
      "sku": "some-real-product-id",
      "name": "Молоко 3,2%, 1 л",
      "priceKopecks": 11990,
      "packages": 2,
      "matchScore": 0.96,
      "exactMatch": false,
      "url": "https://magnit.ru/"
    }
  ]
}
```

Для агрегаторов `storeId` должен быть формата `kuper:<real-outlet-id>` или `yandex_eda:<real-outlet-id>`. **Разные магазины внутри одного агрегатора не объединяются в одну доставку.** При этом прямой заказ в Перекрёстке и заказ через Купер в Перекрёстке — разные каналы с разными ценами и комиссиями; сравнивать их можно, но нельзя автоматически считать двумя отдельными наличными складами без дополнительной проверки.

Чтобы зафиксировать отсутствие доставки по адресу, адаптер возвращает `{"addressChecked":true,"available":false,"stores":[],"offers":[]}`. Пустой непроверенный ответ считается **«нет подтверждённой стоимости»**, а не «магазин недоступен».

## Точность сравнения

Оптимизатор рассматривает только присланные котировки с положительными ценами и известной доставкой. Отсутствующие данные **не приравниваются к нулю**. Он показывает предварительное решение, пока все обязательные сервисы и дополнительно найденные сети не дали адресно подтверждённые ответы или явно подтвердили отсутствие доставки.

Порог разделения остаётся **300 ₽** при максимум двух доставках. При невозможности собрать весь список одним магазином вторая доставка допускается для покрытия списка независимо от порога.

**Ограничения:** даже после подключения адаптеров перед оплатой нужно заново проверить цены, скидки, минимальные суммы, весовые товары, наличие и фактические тарифы на этапе checkout. Промокоды и персональные бонусы ещё не оптимизируются.
