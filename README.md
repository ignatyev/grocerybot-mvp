# Grocery Bot MVP — поиск продуктовой корзины

Поиск доступных сервисов по адресу и оптимизация корзины с максимум **двумя доставками**. Вторая доставка выбирается, когда экономия составляет хотя бы **300 ₽** (или без неё невозможно собрать полный список). Допускаются подходящие аналоги, скорость доставки в оценке не участвует.

## Обязательные сервисы

В России всегда учитываются шесть каналов: **Магнит, Пятёрочка, Перекрёсток, ВкусВилл, Купер, Яндекс Еда**. Магазины не исчезают из отчёта из-за отсутствия точки на карте. Другие сети и локальные магазины обнаруживаются с помощью Nominatim и Overpass/OSM. Приложение **не делает вывод**, что ближайший физический магазин обязательно доставляет по адресу.

Каждый сервис показывает статус: цены подтверждены по адресу, найден каталог без доставки, нет адаптера, ошибка запроса или доставка недоступна. В агрегаторах (Купер, Яндекс Еда) цены относятся к конкретным магазинам/витринам, а не к сервису целиком.

## Источники цен

- **ВкусВилл**: настоящий поиск по публичному MCP `https://mcp.vkusvill.ru/mcp` с ценами товаров. Каталожная цена не подтверждает наличие и адресную цену после входа.
- **Остальные пять обязательных сервисов**: всегда отображаются, но для автоматической проверки адресных цен/условий доставки необходимы их адаптеры. Без них статус **«нет адаптера»**, не вымышленная цена.
- **Дополнительные сети**: определяются по карте и могут быть подключены через такой же адаптер.
- Вручную можно внести проверенные цены и стоимость доставки для тестирования оптимизации.

**Нельзя гарантировать глобально самую дешёвую корзину, пока все магазины не проверены.** Это явно отображается в интерфейсе. [Контракт подключения магазинов](ADAPTERS.md).

## Запуск

Node.js 22+, без установки npm-зависимостей:

```bash
npm test
npm start
```

Откройте `http://localhost:3000`, введите адрес в России, найдите сервисы, затем введите список товаров и запустите поиск цен.

## Railway

В репозитории есть `Dockerfile`. Выберите **Deploy from GitHub Repo** в Railway, затем создайте публичный домен. Переменная `PORT` задаётся платформой. Для публичного инстанса задайте `GROCERYBOT_USER_AGENT` с контактами приложения по требованиям Nominatim. API геокодирования принимает адрес, не используйте в нём конфиденциальные данные.

Для добавления реальных интеграций настройте `GROCERYBOT_ADAPTERS_JSON` и переменные токенов — подробности в [ADAPTERS.md](ADAPTERS.md).

## HTTP API

- `GET /health` — статус сервера.
- `POST /api/discover` — `{ "address": "Россия, Сочи, ул. Навагинская, 9" }`; возвращает `requiredProviders`, `additionalProviders`, `localStores`, `catalogProviders`.
- `POST /api/search` — `{ "list": "молоко 2 л\nяйца 10 шт", "countryCode": "ru", "address": "...", "point": { ... }, "localStores": [], "allowSubstitutions": true }`; возвращает предложения по строкам и отдельный статус каждого провайдера.
- `POST /api/optimize` — `{ "items": [...], "stores": [...], "providers": [...], "allowSubstitutions": true }`; результат дополнен `coverage`, `globalBestVerified`, `scopeNote`.
- `POST /api/cart/vkusvill` — `{ "items": [{ "sku": "1248", "packages": 1 }] }`.

## Ограничения

- Автоматического подтверждения доставки для остальных пяти сетей без адаптеров нет.
- Скидки, промокоды, бонусы и точное checkout-ценообразование ещё не реализованы.
- Подбор аналогов пока не проверяет состав, аллергены и другие существенные характеристики; нужна проверка перед оплатой.
- Оптимизация длинных списков (>12 позиций) использует ограниченный перебор и может быть приближённой.
- Геопоиск OpenStreetMap требует соблюдения лимитов и правил сервисов; запросы кэшируются и ограничиваются. Для высокого трафика нужны собственные геосервисы и очередь запросов.
