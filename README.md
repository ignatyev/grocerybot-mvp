# Продуктовый бот — MVP

Экспериментальный веб-сервис без регистрации и автоматического оформления заказа.

## Что реально работает

- Геокодирование адреса через OpenStreetMap Nominatim.
- Поиск **физических** продуктовых магазинов в радиусе ~5 км через Overpass API. Это **не** подтверждение доставки.
- Для **России**: реальный поиск каталожных товаров и цен ВкусВилл через публичный MCP `https://mcp.vkusvill.ru/mcp`.
- Формирование ссылки на корзину ВкусВилл (до 20 SKU), если MCP вернул ссылку.
- Ручной ввод проверенных пользователем цен из других сервисов; расчёт самого дешёвого варианта для 1 или 2 доставок.
- Правила: максимум две доставки; разделить корзину лишь при экономии >= 300 ₽; аналоги разрешены; скорость игнорируем.

## Что **пока не работает**

- Автоматический доступ к персональным ценам и наличию по адресу (у ВкусВилла для этого требуется отдельный OAuth).
- Достоверные тарифы и окна доставки: пользователь вводит тарифы из checkout. Пока тариф неизвестен, магазин **не включается в оптимальную полную стоимость**.
- Автоматический прайсинг Магнита, Пятёрочки, Ленты и других магазинов. Они обнаруживаются как кандидаты, но не изображаются как подключённые каталоги.
- Промокоды, списание бонусов, точная проверка фасовок, весовые допуски, оформление и оплата заказов.
- Полноценный подбор аналогов по составу/аллергенам: работает текстовое сопоставление, все аналоги требуют проверки пользователем.
- Доказуемая оптимальность на длинных списках (>12 строк): ограниченный эвристический поиск.

## Запуск

Нужен Node.js 20+ (Node.js 22 рекомендован). **npm install не требуется**.

```bash
node --test
npm start
```

Откройте `http://localhost:3000`. Сначала введите адрес и выполните поиск магазинов, затем запустите поиск товаров.

Для публичного инстанса задайте `GROCERYBOT_USER_AGENT` с названием приложения и контактным адресом для сервиса Nominatim (следуйте его политике использования). Адрес отправляется на OpenStreetMap и временно кэшируется в памяти процесса; не используйте чувствительные данные.

## Railway

Проект готов к деплою (есть `Dockerfile` и `package.json`). Можно загрузить папку как GitHub-репозиторий и выбрать **Deploy from GitHub Repo** либо в каталоге проекта запустить:

```bash
railway up -y
railway domain
```

Для Railway требуется отдельная CLI-авторизация либо связанный с Railway OAuth-инструмент, способный деплоить локальные исходники. Подключение приложения Railway **в интерфейсе ChatGPT** не автоматически авторизует CLI в отдельном рабочем контейнере.

## API

- `GET /health` — статус.
- `POST /api/discover` — `{ "address":"Россия, Сочи, ..." }`.
- `POST /api/search` — `{ "list":"молоко 2 л\nяйца 10 шт", "countryCode":"ru", "allowSubstitutions":true }`.
- `POST /api/optimize` — `{ "items":[...], "stores":[{ "id":"vkusvill", "name":"ВкусВилл", "deliveryKopecks": 19900 }] }`.
- `POST /api/cart/vkusvill` — `{ "items":[{ "sku":"1248", "packages":1 }] }`.

Список тестов расположен в `test/optimizer.test.js`.

## Источники

- ВкусВилл MCP: https://github.com/vkustech/vkusvill-mcp-server-manifest
- OSM Nominatim: https://nominatim.org/release-docs/latest/api/Search/
- Overpass: https://wiki.openstreetmap.org/wiki/Overpass_API

Данные публичных сервисов не следует собирать слишком часто; сервер использует краткосрочный кэш и базовый лимит запросов. Для серьёзного публичного трафика нужны отдельные провайдеры геокодирования и долговременная очередь.
